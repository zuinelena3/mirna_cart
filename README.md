# Pre-treatment circulating microRNA signatures predict outcomes of anti-CD19 CAR T-cell therapy

This repository contains all the scripts used to perform the analysis of microRNA (miRNA) omics data from patients treated with anti-CD19 CAR T-cell therapy.

The analyses presented in this repository are described in the following publication:

Naddeo M, Roncarati R, De Felice F, Zuin E, Pace I, Iannotta F, Laprovitera N, Fontana B, Durante G, Salamon I, Storci G, De Matteis S, Ricci F, Bertuccio SN, Messelodi D, Ursi M, Roberto M, Barbato F, Ardizzoia F, Tomassini E, Sinigaglia B, Zazzeroni L, Dan E, Duardo RC, Vaglio F, Tassoni M, Pellegrini C, Gentilini M, Maffini E, Casadei B, Sales G, Zinzani PL, Bonafé M, Ferracin M, Bonifazi F. Pre-treatment circulating microRNA signatures predict outcomes of anti-CD19 CAR T-cell therapy. Haematologica 2026; 111(11):3807-3811; <https://doi.org/10.3324/haematol.2025.300294>.
